Migrating to v1.4

v1 is permanent.v1.2 removes loadstring on AT fail so hooks cannot dump the decoy/AT path as easily.
  • lightcore:tm:v1 — stable forever
  • lightcore:tm:v1.2 — AT-VM, no loadstring on fail
  • Macros: LC_* only

Macros

Use LC_* macros in your source. Ship shims so the script still runs unobfuscated.

if not LC_OBFUSCATED then
  LC_OBFUSCATED = false
  LC_LINE = 0
  function LC_ENCSTR(s) return s end
  function LC_ENCNUM(n) return n end
  function LC_OPAQUE(v) return v end
  function LC_CRASH() error("crash") end
  function LC_NO_VIRTUALIZE() end
  function LC_VM_MAX() end
end

print("line", LC_LINE)
print(LC_ENCSTR("secret"))
if LC_OBFUSCATED then
  -- only kept after obfuscation
end
